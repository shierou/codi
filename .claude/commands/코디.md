사용자 입력: `$ARGUMENTS`

## 할 일

`D:\Private\Codi`에서 `scripts/daily_codi.mjs`를 실행해 **내일 출근 복장** 후보를 제시한다.
이 스크립트가 `index.html`의 실제 엔진(`genCandidates` · `scoreCore` · 전문가 5인 합의)을
헤드리스로 구동하므로, 점수나 조합을 직접 지어내지 말고 **항상 스크립트 출력을 근거로** 답한다.

입력에 따라 아래 중 하나를 실행한다 (작업 디렉터리는 `D:\Private\Codi`):

| 입력 | 실행 |
|---|---|
| 비어 있음 | `node scripts/daily_codi.mjs` |
| `1,3` 처럼 번호만 | `node scripts/daily_codi.mjs --reject 1,3` |
| `확정 2` / `2번으로` | `node scripts/daily_codi.mjs --pick 2` |
| `리셋` | `node scripts/daily_codi.mjs --reset` |
| `오늘` | `node scripts/daily_codi.mjs --date <오늘 날짜(KST)>` |

## 결과 제시 방법

1. 맨 위에 **날짜 · 날씨 한 줄**(최고/최저, 아침·저녁 체감, 강수확률)을 적는다.
2. 후보 3개를 **번호를 붙여** 아우터 / 상의 / 하의 / 신발 순으로 보여준다.
   - 아우터는 낮 최고기온이 아니라 **아침·저녁 체감((최고+최저)/2)** 기준으로 배정된다.
     한여름(6~8월, 최저 18° 초과)이 아니면 아우터는 필수이므로 임의로 빼지 말 것.
3. 각 후보마다 전문가 코멘트 중 **가장 판단에 도움이 되는 1~2줄만** 골라 붙인다(5개 전부 나열 금지).
4. 마지막에 반드시 다음 행동을 안내한다:
   `마음에 안 드는 번호를 알려주세요 (예: /코디 1,3) · 확정은 /코디 확정 2`

## 주의

- 제외는 조합 시그니처 + 그 후보의 상의 코드까지 함께 걸리므로, 재추천에서는 제외한 상의가
  다시 나오지 않는다. 후보가 고갈되면 스크립트가 스스로 제외를 완화하고 그 사실을 `note`로 알려준다.
- 소재 손상·이염 같은 **검증되지 않은 근거로 후보를 깎거나 제외하지 말 것.**
- 사용자의 핏 선호(레귤러·스트레이트)는 시장 트렌드(와이드·커브드)와 반대다. 트렌드를 이유로
  선호를 뒤집지 말 것.
- 스크립트가 실패하면(`ERROR:`) 원인을 그대로 알리고, 날씨 API 오류라면 잠시 후 재시도를 권한다.
